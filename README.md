# SGB · Patrones de Diseño y Buenas Prácticas — UPANA

Presentación interactiva (14 diapositivas) sobre un Sistema de Gestión de Bibliotecas (SGB)
de la Universidad Panamericana de Guatemala.

**Expositores:** José Pablo Ibañez Ibañez (1–7) · Diego Josue Melgar Monzón (8–14)

## Archivos
- `index.html`: estructura de las diapositivas
- `style.css`: estilos y animaciones
- `script.js`: lógica, patrones, diagramas e interactividad
- `logo.png`: logo institucional (reemplace este archivo por el logo oficial de UPANA)

## Uso
Abra `index.html` en el navegador. Navegación: flechas, barra espaciadora, Inicio/Fin o el menú.
El logo se carga primero desde Wikimedia y, si no hay conexión, desde `logo.png`.

## Publicar en GitHub Pages
Settings → Pages → Deploy from branch → `main` / `(root)`.
